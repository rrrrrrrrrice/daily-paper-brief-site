研究背景

由原简报的核心问题、选取理由和相关性整理，不替代原文背景综述。

视频生成的 KV 缓存压缩通常对所有层和头使用统一合并率，但不同位置对压缩的敏感度差异很大。统一比例可能浪费预算，也可能损害关键运动证据。 从本日报的选取理由看，CALM 证明层和注意力头对 Token 合并的敏感度具有稳定结构，并用离线风险图和动态规划分配预算，适合作为 P4 研究中预算分配和压缩风险代理的直接基线。

核心问题

如何在给定缓存预算下，把更多 Token 保留给高风险层头，同时用低成本指标预估端到端质量损失。 对当前主题的关键意义在于：可迁移模块是离线风险校准、层头预算分配和动态规划，对应 P4 的自适应 Token 预算和系统级显存收益。预期在相同预算下减少质量损失，风险是离线风险图不覆盖跨模态可靠性和瞬态前兆。最小实验是在现有图像 patch 或时序 Token 上学习风险图，比较统一比例、重要性硬删和 CALM 式预算分配的事件召回、FLOPs、峰值显存与 P99 延迟。

方法与关键创新

离线估计各层各头的注意力输出误差，用它作为视频质量风险代理，形成固定风险图。在线给定预算时，通过动态规划选择层头合并比例。 阅读时需要把方法设计与主要结果一起看：在 3 个自回归视频模型上，相同内存预算下持续优于统一 Token 合并，报告相对原视频 LPIPS 约降低 21%，并获得更高视频质量分数。

实验结果

在 3 个自回归视频模型上，相同内存预算下持续优于统一 Token 合并，报告相对原视频 LPIPS 约降低 21%，并获得更高视频质量分数。

局限性

压缩对象是视频生成 KV 缓存，不是事件流或诊断多模态 Token。离线风险图对模型、提示和数据分布变化的稳定性还需要验证，短暂稀有事件召回也未直接报告。

总结

CALM 把压缩从固定保留率转成风险感知的预算分配。

核心问题

块级并行去噪能否在保持预测表示质量的同时，减少纵向长序列的顺序生成开销。 对当前主题的关键意义在于：可迁移模块是块级并行建模和冻结表示比较，对应 P1 的高频长序列低延迟建模。预期降低串行推理延迟，风险是块边界可能切断短暂前兆。最小实验是在诊断 Token 上比较自回归、块扩散和选择性块大小，测量前兆召回、端到端延迟、峰值显存和跨采样率鲁棒性。

实验结果

局限性

主要评估是 EHR，块结构对真实异步诊断流和突发事件的适配未验证。生成质量仍多数低于自回归模型，去噪预算增加也存在收益递减。

总结

多参数成像拟合存在参数退化和噪声敏感问题，仅依靠信号曲线容易产生不稳定解。解剖图像提供空间先验，但直接拼接会把无关组织信息引入拟合。 从本日报的选取理由看，PACE 将信号时序、解剖图像、交叉注意力、选择性空间门控和物理约束结合，提供了“时序查询图像局部证据”的可迁移范式，适合作为 P3 的跨领域机制候选。

核心问题

如何选择性地利用多模态空间信息稳定信号参数重建，同时保留物理模型的可解释约束。 对当前主题的关键意义在于：可迁移模块是时序与图像交叉注意力、选择性门控和物理空间先验，对应 P3 的图像局部证据选择与物理解释。预期通过减少无关视觉 Token 降低融合计算，风险是空间先验可能在跨装置几何变化时错误约束。最小实验是在现有诊断时序与可见光帧上用时序查询局部 patch，比较全图拼接、交叉注意力和门控先验的提前量、跨装置 AUROC、显存和解释一致性。

方法与关键创新

PACE 用并行分支编码 IVIM 信号和 T1w、FLAIR 图像，通过交叉注意力和选择性空间门控融合，并加入解剖加权空间先验约束邻近体素重建。 阅读时需要把方法设计与主要结果一起看：PACE 变体在除 Dmv 外的参数上降低 RMSE。加入解剖空间先验后，五个参数的 RMSE 进一步下降，在体数据上对不同噪声水平的信号重建最好，并保持良好 ICC。

实验结果

PACE 变体在除 Dmv 外的参数上降低 RMSE。加入解剖空间先验后，五个参数的 RMSE 进一步下降，在体数据上对不同噪声水平的信号重建最好，并保持良好 ICC。

局限性

原始应用是 MRI 参数拟合，不是托卡马克破裂预测。跨装置域适配、异步采样、低延迟部署和模态缺失没有展开。

总结

PACE 展示了物理信号查询视觉局部证据，而不是简单拼接全图的实现路线。

研究相关性与启发

可迁移模块是时序与图像交叉注意力、选择性门控和物理空间先验，对应 P3 的图像局部证据选择与物理解释。预期通过减少无关视觉 Token 降低融合计算，风险是空间先验可能在跨装置几何变化时错误约束。最小实验是在现有诊断时序与可见光帧上用时序查询局部 patch，比较全图拼接、交叉注意力和门控先验的提前量、跨装置 AUROC、显存和解释一致性。

趋势判断

1. 在线时序系统开始把预测和校正分离

DRiC 说明冻结预测器之后仍可用很小的递归状态完成在线修正，下一步是把真实 Δt、异步通道和突发事件守卫纳入同一状态接口。

2. 多模态融合从可用性走向可靠性

GAMF-Net 与可靠性 PoE 分别处理可用模态和可信模态，下一步应把时间错位、事件稀疏和跨装置漂移纳入可靠性校准。

3. 物理先验正在改变视觉融合的位置

PACE 的信号查询局部图像和空间先验适合迁移到诊断时序与可见光图像，但直接破裂预测仍缺少合格新增。

4. Token 压缩开始显式分配风险预算

CALM 说明固定保留率不是唯一选择，后续需要把离线风险图、模态可靠性、短暂事件召回和真实端到端延迟统一起来。
